# Local fonts

These Latin-subset WOFF2 files are bundled locally so the portfolio does not rely on a font CDN:

- Space Grotesk variable (weights 300–700)
- DM Mono (weights 400 and 500)
- DM Serif Display Italic (weight 400)

Source packages: `@fontsource-variable/space-grotesk@5.3.0`, `@fontsource/dm-mono@5.3.0`, and `@fontsource/dm-serif-display@5.3.0`. Each font is licensed under the SIL Open Font License 1.1; the full notices are included beside the font files.
